# Example inputs

Small inputs used to check that each program builds and runs after the clean-up. The formats follow the assignment sheets:

| Program | How to run from this directory |
|---|---|
| 05 | run `month_calendar`, then type `2024 2` |
| 06 | copy `06_input.txt` to `input.txt`, run `second_largest_pooling` → prints `13` |
| 07 | copy `07_input.txt` to `input.txt`, run `count_islands` → prints `3` |
| 08 | copy `08_input.txt` to `input.txt`, run `circular_queue` (each line after the count is one command: `E` + character, or `D`) |
| 09 | `merge_sorted_strings 09_input.txt` → `aabBcDeFz` |
| 10 | `student_records 10_input.txt` → writes `output_4.txt` |
| 11 | run `sorted_linked_list`, type `11_input.txt` at the prompt (commands are `I n` / `D n` with a single-digit n) |
| 12 | `yearly_averages 12_data_csv.csv SP` → writes `SP_12_data_csv.csv.dat` with the yearly means of the SP column (the real assignment input was the monthly Shiller data set, which has the same column layout) |
